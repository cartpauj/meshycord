Discord

Never displayed back. Leave blank to keep the stored one. Open any channel in your server; the first long number in the browser URL is the server ID. Every channel and category is created for you.

Bot setup checklist

In the Discord Developer Portal, the bot needs Message Content Intent turned on, Public Bot turned off, and these permissions: View Channels, Send Messages, Read Message History, Manage Channels, Manage Messages.

Radio link

If this box sits next to the radio, USB serial is the most reliable option: no pairing, no PIN, no bonding, and no dropped links.

Bluetooth LE

Blank matches the first device advertising the MeshCore service. Wins over the name when set. The node must have a fixed PIN set in the MeshCore phone app. Without one it generates a random PIN each boot and shows it on its screen, which a headless bridge cannot read. MeshCore's own default is 123456.

TCP

For MeshCore's WiFi companion firmware. Port 5000 is assumed if you leave it off.

Policy

What the bridge is allowed to create in Discord without being asked.

Safe: your node's channels are already yours, so there is no abuse surface here. Off by default: there are often dozens, which fills a server and hits Discord's 50-channels-per-category limit. The riskiest of the three: anyone who has heard your advert can send you a direct message. Even when this is on, it only fires for senders already in the radio's contact list — an unknown sender always goes to the inbox, which is the guard that makes the whole policy safe. A mesh message is 133 bytes; longer text is split. Anything needing more transmissions than this is refused rather than truncated — truncating looked like it sent, which was worse. At {{.Cfg.MaxChunks}} that is about {{.ChunkCapacity}} characters of plain text. Airtime is shared with everybody else on the mesh. Room servers silently discard posts from anyone whose session has lapsed, and never say how long a session lasts — so the bridge logs in again once this window passes. 0 logs in before every message: the most reliable setting, and it costs a full round trip over the air per post, which roughly doubles the airtime a room conversation uses. 0 keeps everything. History lives on the SD card, so a bound is worth having.

Console login

This page holds your bot token and every room password. At least 8 characters. Changing it signs out every other session.

Danger zone

Reset deletes every channel the bridge created — all linked channels, the Channels / Room Servers / Companion DMs categories, and the inbox — and clears every link. Channels you made yourself are untouched.
